# Академия: витрины авторов (11.10.2026)

Владелец: Виктор. Исполнитель: эта сессия (Core + сайт + инфраструктура + almira.by).

## Цель

Одно ядро Академии — разные витрины. Курсы, ученики, доступы, домашки и медиа
хранятся в одном тенанте `whieda`. Витрина — строка `academy_showcases`: хосты,
автор-владелец, бренд, бот, правило «ещё курсы». Она меняет только оформление,
порядок курсов и бота; права доступа от неё не зависят.

Первая витрина — арт-студия ALMIRA: `academy.almira.by`, бот `@ALMIRA_I_bot`.

## Решения владельца (11.10.2026)

- Бот витрины ALMIRA — `@ALMIRA_I_bot` (сейчас шлёт заявки с almira.by через
  `lead.php`; отправку не трогаем). Подключается вторым binding тенанта whieda.
- MAX: бот WHIEDA в MAX зеркалит Telegram; бот ALMIRA в MAX — позже. В этом срезе
  MAX не делаем, но витрина хранит канал так, чтобы MAX добавился полем.
- Адрес — `academy.almira.by`. DNS-запись делаем мы (нужен доступ к DNS hoster.by).
- Согласие — как на almira.by: обязательная галочка с политикой перед входом.
- С Сашей партнёрство (договор 30 % новых онлайн-направлений вне системы):
  «Академия автора» для неё без оплаты.
- Авторов мало, только партнёры: витрины заводим руками по шаблону.
- Перекрёстные продажи пока не делаем: «ещё курсы» выключены (`more_mode = none`),
  купленные курсы видны на любой витрине.
- Диск московского прокси можно расширить.
- Решения ARCHITECTURE_V1 №3–4 (сторонние авторы в тенанте saas) заменяются этим:
  все авторы в тенанте whieda.

## Срез

Core (`core/academy-showcase-20261011` от развёрнутого `35c0bd6`):
1. Миграция V29 `academy_showcases`.
2. Витрина запроса: `X-WWC-Showcase-Host` → `X-Forwarded-Host` → `Host`;
   `?showcase=<id>` — только для предпросмотра оформления.
3. `GET /api/v1/content-access/academy/showcase` без входа: бренд, тема, бот, ссылки.
4. `/courses`: свои курсы первыми, `section own|more`, `more_mode`.
5. Вход: бот deep link по витрине; хосты витрин разрешены в `return_to`,
   `with_site_login`, `/tg-open/`.
6. Бот витрины: только Академия (вход, ключи, курсы, «мои курсы»), личка;
   группы и всё остальное молча.
7. Ссылки бота и уведомлений — на витрину автора курса, отправка — её ботом.
8. Партнёр-владелец витрины = автор без оплаты «Академии автора».

Сайт (`site/academy-showcase-20261011` от развёрнутого `3a74816`):
конфиг витрины до входа, токены бренда, тексты без «WWC/Виктор», галочка согласия,
два блока курсов.

Инфраструктура: `edge.wwc.best` (Cloudflare, DNS only) → московский прокси;
server-блоки `academy.almira.by` на прокси и origin; сертификат; заголовок витрины
в Академии на wwc.best; буферизация видео на прокси; проверка продления `*.wwc.best`.

almira.by: кнопка «Академия», тексты про закрытую группу, политика (раздел Академии).

## Не входит

MAX-канал Академии, оплата на сайте, «ещё курсы» и учёт перекрёстных продаж,
автоматизация подключения витрин.
