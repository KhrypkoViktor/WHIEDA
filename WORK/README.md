# WORK - принято и используется в бою

Здесь лежат только утвержденные источники данных и документы, от которых разрешено собирать production.

- data-contracts - зафиксированные выгрузки мастер-реестров и их manifest.
- Изменение данных допускается только отдельным запросом владельца.
- Парсинг официальных сайтов не имеет права молча менять WORK.
- Черновики и аудиты хранятся в ../PROCESS.
- Снятые материалы переносятся в ../ARCHIVE, а не удаляются.
