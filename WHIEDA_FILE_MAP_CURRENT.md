# WHIEDA: актуальная карта проекта

Дата: 2026-09-04
Статус: единственная актуальная карта файлов проекта. Заменяет версию от
2026-07-26 (сохранена в `99_Archive/Superseded_File_Maps/`).

## 1. Правило входа

Перед любой работой в WHIEDA читать в таком порядке:

1. `00_READ_FIRST_WHIEDA_CANON.md` — правила и принятые решения, включая раздел
   «Известные пробелы этого списка» — часть канонических документов физически
   отсутствует, это не баг карты, это факт репозитория на 2026-09-04.
2. Этот файл: `WHIEDA_FILE_MAP_CURRENT.md`.
3. `WHIEDA_WORKSPACE_CONSOLIDATION_2026-08-31.md` — пока не завершён разбор
   сохранённого workspace snapshot.
4. `WHIEDA_ACCESS_MAP_PRIVATE_2026-07-07.md` — только если работа требует
   live-доступов.
5. Нужный тематический документ из корня (см. раздел 2).

Старые карты — `99_Archive/`. Они не являются рабочей инструкцией.

## 2. Три физические зоны (введено 2026-09-04)

- **корень** — только каноны: правила, карта, живые backlog'и и документы,
  явно процитированные в `00_READ_FIRST_WHIEDA_CANON.md`. Ничего временного,
  ничего «для одного агента на один прогон».
- **`WORK/`** — принято владельцем и используется в production
  (`data-contracts/` — зафиксированные выгрузки мастер-реестров и их manifest).
- **`PROCESS/`** — в работе, не принято: ТЗ для конкретного исполнителя,
  аудиты, кандидаты, GLM/агентские задания. Отсюда запрещено собирать и
  деплоить.
- **`99_Archive/`** — заменяет удаление. Единственный архив проекта (не
  плодить второй). Из него запрещено импортировать данные или код.
  `ARCHIVE/`, созданный на один день 2026-09-04, удалён владельцем — не
  создавать заново.

## 7. Правила порядка (не нарушать в следующий раз)

- Новый файл для одного исполнителя/агента — в `PROCESS/`, никогда в корень.
- Корень получает новый документ только если без него нельзя начать работу и
  он проходит проверку «это канон, а не текучка».
- Отработанный `PROCESS/`-файл после приёмки владельцем — в `99_Archive/`, не
  оставлять лежать «на всякий случай» в процессной папке.
- Один архив, не два. Если завёл второй — слить в `99_Archive/` или удалить
  пустой, не наполнять параллельно.
- При архивации файла, на который прямо ссылается канон, — либо чинить ссылку
  в каноне в том же движении, либо явно пометить пункт как известный пробел
  (см. `00_READ_FIRST_WHIEDA_CANON.md`, «Известные пробелы»). Не оставлять
  канон молча врущим о том, что где-то лежит.
